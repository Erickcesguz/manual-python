# Introducción a Python

Python es un lenguaje de programación que se caracteriza por tener una sintaxis sencilla y fácil de comprender.

## ¿Para qué sirve?

Python se puede utilizar para:

- Desarrollo web.
- Automatización de tareas.
- Inteligencia artificial.
- Análisis de datos.

## Características

- Es fácil de aprender.
- Tiene muchas bibliotecas.
- Es de código abierto.
