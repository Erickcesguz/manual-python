# Instalación de Python

Para comenzar a utilizar Python, primero debemos instalarlo en nuestra computadora.

## Pasos para instalarlo

1. Ingresar al sitio oficial de Python.
2. Descargar el instalador.
3. Ejecutar el instalador.
4. Seguir las instrucciones de instalación.
5. Comprobar que Python funciona desde la consola.

## Sitio oficial

https://www.python.org/
