
# Ejemplos básicos de Python

Python permite realizar diferentes operaciones mediante instrucciones sencillas.

## 1. Mostrar un mensaje

```python
print("Hola mundo")
```

Este comando muestra un mensaje en pantalla.

## 2. Crear una variable

```python
nombre = "Carlos"
print(nombre)
```

Una variable permite guardar información para utilizarla posteriormente.

## 3. Realizar una suma

```python
numero1 = 10
numero2 = 5

resultado = numero1 + numero2

print(resultado)
```

Este ejemplo suma dos números y muestra el resultado.
